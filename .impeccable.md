# Design context — kurzy.vibecoding.cz

Tento soubor zachycuje sdílený design context pro AI-asistované úpravy UI.
Aktualizovat ručně, když se brand / cílovka mění. Generováno autonomně z
landing.tsx + CLAUDE.md (2026-05-19); můžeš ho upravit kdykoli.

## Target audience

- Česky mluvící profesionálové **bez** programátorského backgroundu —
  projektoví manažeři, produkťáci, analytici, junior devs.
- Věk 28–50, znalost AI nástrojů nulová až střední, motivace získat
  praktickou skill aniž by museli "studovat programování".
- Nakupují jednotlivě (B2C 2 000 Kč) nebo přes firmu (B2B 15 000 Kč licence
  na celou doménu).

## Use cases

1. **Landing → checkout**: rychle pochopit nabídku, zaplatit kartou (Stripe)
   nebo převodem (FIO + QR), získat magic-link login.
2. **B2B objednávka s fakturou**: zadat IČO, načíst z ARES, dostat
   zálohový doklad pro účtárnu schválit, faktura PDF po platbě.
3. **Sledování kurzu**: watch.tsx přehrávač + progress tracking.
4. **Admin**: udělování grantů, správa uživatelů (jen Patrick).

## Brand personality / tone

- **Pragmatický, ne hype.** "Konečně česky, strukturovaně" je správný register.
- **Lehce sebevědomý**: Patrick = autor, věří v hodnotu, ale nepřehání marketing-speak.
- **Knižní bez naparování**: dlouhé věty se středníky jsou OK, ale ne přehnaně.
- **Vyhnout se**: "Silicon Valley hype", "transformative AI", anglické buzzwords.

## Visual language

- **Fonty**: Space Grotesk (display) + IBM Plex Mono (technical/code).
  Žádný Inter/Roboto/Arial.
- **Primární brand barva**: indigo-600 (#4f46e5) — vibecoding fialovo-indigo.
- **B2C accent**: indigo (předplatné jednotlivce).
- **B2B accent**: amber/orange (firemní licence) — odlišuje od B2C.
- **Neutrály**: gray-700 až gray-900 pro text, gray-100/200 pro borders.
- **Žádné gradienty** pro decoration. Pokud gradient, tak utlumený a s důvodem.
- **Žádný dark mode** — jednoznačně light-only.

## Layout principles

- **Asymetrie není priorita** — checkout/dashboard mají centered card layout
  (typický nákupní flow); landing/watch mají širší volnější layout.
- **Plochá hierarchie** — vyhýbat se card-in-card, raději separátory + bílá plocha.
- **Mobile-first** — Tailwind `sm:`/`md:` breakpointy. Touch targets ≥ 44px.

## What to avoid (AI tells)

- Gradient submit buttons (indigo→violet, amber→orange) — neimitovat AI šablonu.
- Nadbytečné `font-mono` mimo skutečně technický obsah (kód, IBAN, VS).
- Glassmorphism, neon-on-dark, AI cyan-on-purple.
- "Hero metric" layouty s velkými čísly.
- Generic `shadow-lg` všude.

## Tech stack constraints

- **Hono JSX SSR** + htmx pro interaktivitu (žádný React/Vue).
- **Tailwind v4** (utility-first, žádný design token system zatím — TODO).
- **Cloudflare Workers** runtime → žádné Node-only API.
- **D1 + Drizzle** ORM, schema versioned přes drizzle migrations.

## Differentiation

To, co web odlišuje od konkurence:
- **Česky a srozumitelně** — žádné anglické termíny bez vysvětlení.
- **Pragmatický autor** s tváří (Patrick Zandl + Andrea Maloveczká).
- **Firemní pipeline funguje** — IČO/ARES/ZD/Fakturoid bez papírové ručky.

## Component conventions

- Buttons: `font-semibold` (ne `font-bold`), `rounded-lg`, solidní barvy.
- Inputs: `rounded-lg border-gray-300 focus:ring-2 focus:ring-indigo-500`.
- Cards: jedna úroveň — `bg-white border border-gray-200 rounded-xl`.
- Callout boxes: `bg-{color}-50 border border-{color}-200` (amber=info,
  red=error, green=success).
