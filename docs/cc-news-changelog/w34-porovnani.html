Week 34: publikovaný článek vs. článek ze changelogu

Stejné období: verze v2.1.234–v2.1.239 (203 položek changelogu). A publikovaný článek z oficiálního přehledu Anthropicu (kurzy.vibecoding.cz/novinky-cc/2026-w34-novinky) · B náš článek ze changelogu. Hodnocení: anthropic/claude-sonnet-5.5.

Verdikt

B není plnohodnotná náhrada A: chybí mu /design a hlavní příběh Remote Control z telefonu, tedy dvě ze tří velkých novinek. Hodí se jako doplněk, ze kterého stojí za převzetí claude-api skill, prompt cache, headersHelper, odstranění zkratky /clear a změna nákladů; číslování verzí je třeba před použitím opravit.

A je čtivější a má jasnou strukturu (tři velká témata, „Proč na tom záleží“, závěr podle typu uživatele), ale část obsahu zřejmě pochází z oficiálního přehledu a v changelogu ji nenajdeme (/design, GA Remote Control). B je přesnější a hlubší u CLI detailů (prompt cache, claude-api skill, headersHelper, náklady, odstranění zkratky /clear), ale bez /design a bez Remote Control z telefonu mu chybí dvě ze tří hlavních novinek A. Nese i několik chybných číslování verzí. Interpretační pasáže B jsou užitečné, ale někdy spekulativní (čeština ve spellchecku, „rychlejší čerpání limitu“).

A publikovaný článek

Stručnější výstupy, návrhové plátno a ovládání z telefonu: novinky v Claude Code za 34. týden

Za 34. týden (17.–21. srpna 2026) prošel Claude Code verzemi 2.1.234 až 2.1.239. Jde o středně velké vydání se třemi výraznými liniemi: novým stylem výstupu Concise zaměřeným na úspornost, příkazem /design, který vtahuje workflow UI prototypování přímo do CLI, a přechodem Remote Control z výzkumného preview do plné dostupnosti včetně mobilní aplikace. Vedle toho přibyla řada drobností posilujících komfort — od kontroly pravopisu přes mezisezení komunikaci po přizpůsobení klávesových zkratek.

Přehled velkých změn

  • Nový styl výstupu Concise — kratší odpovědi bez ztráty přesnosti (v2.1.237)
  • Příkaz /design s plátnem upravitelných artboardů (research preview, od v2.1.234)
  • Remote Control z výzkumného preview do produkce; ovládání sezení z telefonu (mobile)

---

Velké změny

Styl výstupu Concise

Claude nově nabízí vestavěný styl výstupu s názvem Concise. Oproti výchozímu stylu vynechává preambuli a průběžnou naraci — rovnou prezentuje výsledek. Hloubka práce zůstává stejná jako v Default stylu; zkracuje se jen to, co není informačně nezbytné. Pokud uživatel výslovně požádá o vysvětlení nebo větší detail, Claude odpoví plně. Chybová hlášení, bezpečnostní varování a potvrzení destruktivních akcí si uchovávají úplný obsah bez ohledu na zvolený styl.

Proč na tom záleží: Uživatelé, kteří mají Claude Code zapojený do delšího pracovního toku nebo sledují výstup v terminálu periferním pohledem, ocení, že nemusí přeskakovat úvodní odstavce. Concise přitom nezkracuje tam, kde zkratka škodí — chyby a destruktivní akce zůstávají čitelné v plné délce. Jde o dobré rozlišení mezi „méně slov" a „méně informací". (v2.1.237) — Dokumentace: vestavěné styly výstupu

---

Příkaz /design — návrhové plátno v CLI

Příkaz /design přináší do Claude Code CLI a aplikace Desktop workflow Claude Design postavený na artefaktech. Stačí zadat krátký brief a Claude publikuje plátno s upravitelnými artboardy pro vaše uživatelské rozhraní. Jeden artboard lze vybrat, upravit a nechat Clauda přímo implementovat. Funkce je dostupná na plánech Pro, Max, Team a Enterprise, vyžaduje verzi 2.1.234 nebo novější a je zatím označena jako research preview.

Proč na tom záleží: Dosud bylo návrhové plátno odděleno od vývojového procesu — nyní lze projít od skici přes výběr varianty k implementaci v jediném Claude Code sezení bez přepínání nástrojů. Pro vývojáře, kteří navrhují vlastní rozhraní bez dedikovaného designéra, to smysluplně zkracuje cestu od nápadu ke kódu. Research preview nicméně znamená, že chování se může měnit. (research preview, od v2.1.234) — Dokumentace: dostupnost artefaktů

---

Vzdálené ovládání sezení z telefonu

Remote Control opouští výzkumné preview a vstupuje do plné dostupnosti. Každý stroj s běžícím příkazem claude remote-control se zobrazí jako karta zařízení v záložce Code v mobilní aplikaci Claude. Nové sezení tak lze spustit přímo z telefonu. Z mobilní aplikace nebo z claude.ai/code lze navíc měnit úroveň úsilí — změna se okamžitě projeví v sezení na počítači. Sezení hostovaná aplikací Desktop nebo rozšířením VS Code navíc zobrazují připojeným zařízením aktuální režim oprávnění.

Proč na tom záleží: Přechod z preview do produkce signalizuje, že Anthropic považuje funkci za stabilní. Schopnost měnit úroveň úsilí a sledovat režim oprávnění z telefonu dává uživatelům přehled o běžících sezení bez nutnosti sednout k počítači — užitečné zejména u dlouhotrvajících úloh spuštěných na vzdáleném stroji. (mobile) — Dokumentace: spuštění sezení Remote Control

Drobnosti

  • Claude Code po resetování limitu využití na claude.ai automaticky pokračuje v sezení; lze vypnout v /config na řádku „Continue automatically at usage limit"
  • Volitelné nastavení kontroly pravopisu podtrhuje chybně napsaná slova přímo v poli promptu za použití nainstalovaného aspell, hunspell nebo ispell
  • Na větvi s otevřeným merge requestem na GitLabu zobrazuje zápatí odznak MR !N s barvou odpovídající stavu (draft, open, mergeable); vyžaduje autentizovaný glab CLI
  • Změna úrovně úsilí z telefonu nebo claude.ai/code se projeví v sezení na počítači; sezení hostovaná Desktopem nebo VS Code zobrazují připojeným zařízením aktuální režim oprávnění
  • Oprávnění /permissions lze otevřít a /add-dir spustit i v průběhu práce Clauda; změny pravidel se uplatní pro zbytek aktuálního tahu
  • Při čekání na úlohy na pozadí /goal Claude zkontroluje jejich stav po 30 minutách místo čekání na neurčito; při nečinnosti sezení se intervaly prodlužují; CLAUDE_CODE_GOAL_CHECKIN_MINUTES=0 přihlašování vypne
  • Vlastní prompty se v přepisu nyní vykreslují jako markdown — zvýrazněné bloky kódu, inline kód i seznamy — stejně jako odpovědi Clauda
  • Proměnná prostředí ANTHROPIC_DEFAULT_MODEL nastavuje výchozí model pro nová sezení; výběr přes /model ji přepisuje a přetrvává přes restarty
  • Se vstupem notify_when_idle u SendMessage může Claude požádat jiné sezení Claude Code na tomtéž stroji, aby zaslalo oznámení při příštím přechodu do nečinnosti
  • Nastavení keybindingFlavor na hodnotu "readline" zajistí, že Ctrl+W v promptu maže zpět po mezeru jako v Bashi, nikoli po interpunkci jako /
  • Na nativním Windows mohou sezení Claude Code navzájem komunikovat přes SendMessage a vzájemně se nacházet přes ListAgents, stejně jako na macOS a Linuxu
  • Vlastní hostované spouštěče (self-hosted runners) přijímají --defer-shutdown-max-min, který udržuje připojená sezení aktivní po zadaný počet minut po přijetí SIGTERM
  • Vlastní hostované spouštěče přijímají --proxy-authorization-command nebo --proxy-authorization-file pro dodání čerstvé hlavičky Proxy-Authorization výstupním proxy vyžadujícím autentizaci

Závěr

34. týden přinesl změny, které jsou zajímavé každý pro jiný typ uživatele. Styl Concise ocení ti, kdo Claude Code zapojují do hustých pracovních toků a nepotřebují průvodní komentář — zkrátka chtějí výsledek. Příkaz /design míří na vývojáře pracující samostatně na produktech s vlastním rozhraním: spojuje skicování a implementaci do jediného sezení. Nejširší dosah má pravděpodobně přechod Remote Control do produkce — možnost spustit, sledovat a řídit sezení z telefonu mění to, jak lze s Claude Code pracovat při pohybu nebo na vzdálených strojích. Drobnosti pak doplácejí detaily, které každodenní používání cizelují: od kontroly pravopisu a markdown v promptech po ladění chování /goal a nové možnosti pro správce vlastní infrastruktury.

B článek ze changelogu

Claude Code se po vyčerpání limitu sám rozběhne, mluví stručněji a lépe spolupracuje mezi relacemi

Verze 2.1.234 až 2.1.239 nepřinášejí žádný převratný release, ale soustředěné vylepšení pracovního postupu. Linie změn jsou tři. První je větší samostatnost: Claude Code po obnovení limitu pokračuje sám a /goal si hlídá úlohy na pozadí. Druhá je lepší koordinace relací, včetně příchodu na Windows. Třetí je pohodlí při psaní a čtení: nový stručný styl výstupu, kontrola pravopisu a dialogy dostupné i uprostřed běžícího kroku. Drobnosti pak zahrnují úsporu při načítání skillu claude-api, opravy prompt cache a podporu GitLabu.

Přehled velkých změn

  • Zprávy mezi relacemi: notify_when_idle a podpora Windows (v2.1.236)
  • /goal s chytřejšími kontrolami a zotavením (v2.1.239)
  • Automatické pokračování po obnovení limitu na claude.ai (v2.1.234)
  • Dialogy otevřené za běhu práce Claudea (v2.1.234)
  • Vestavěný styl výstupu „Concise" (v2.1.237)
  • Kontrola pravopisu v promptu (v2.1.235)

Zprávy mezi relacemi: notify_when_idle a podpora Windows

SendMessage získává volbu notify_when_idle. Požádá jinou relaci Claude Code na stejném stroji, aby poslala jedno upozornění, až bude příště nečinná. Je to volitelné, jednorázové, bez opakovaného dotazování a podporu mají macOS a Linux. Zprávy mezi relacemi nově fungují také na Windows. Odesílatel navíc dostane výslovnou zpětnou vazbu, když je zpráva odmítnuta nebo zahozena, a ListAgents vypíše aktivní členy týmu.

Interpretace: kdo provozuje více relací současně, dosud musel stav ostatních hlídat ručně. Jednorázové upozornění při nečinnosti je přesně ten mechanismus, který z paralelních relací dělá použitelný tým. Zpětná vazba při odmítnutí zprávy odstraňuje tiché selhávání. Největší přínos mají uživatelé Windows, kteří se k této funkci dostali poprvé. (v2.1.236) Dokumentace

/goal s chytřejšími kontrolami a zotavením

Pokud cíl čeká na úlohy na pozadí, Claude je nově sám zkontroluje po 30 minutách, pak v rozestupech 1 hodiny a 2 hodin. Cíl se také sám zruší s upozorněním, když krok skončí neopravitelnou chybou. Obnovení z výběru claude --resume vrátí aktivní cíl. Kontroly lze vypnout nastavením CLAUDE_CODE_GOAL_CHECKIN_MINUTES=0.

Interpretace: u dlouhých úloh se /goal dosud mohl zaseknout, aniž by si toho někdo všiml. Postupně řidnoucí kontroly řeší čekání na pozadí bez zbytečného zahlcování. Samočinné zrušení cíle po fatální chybě zase brání tomu, aby relace vypadala aktivně, zatímco už nic nedělá. Prospěje to všem, kdo nechávají Claude pracovat bez dozoru. (v2.1.239) Dokumentace

Automatické pokračování po obnovení limitu

Claude Code nově sám pokračuje v relaci, jakmile se obnoví limit využití na claude.ai. Chování lze vypnout v /config pod položkou „Continue automatically at usage limit".

Interpretace: spolu s /goal je to další krok k úlohám, které přežijí i narazení na limit, bez ručního „pokračuj". Kdo si spotřebu limitů hlídá pečlivě, měl by si nastavení v /config zkontrolovat, protože souvislá práce může znamenat rychlejší čerpání. (v2.1.234) Dokumentace

Dialogy otevřené za běhu práce Claudea

/permissions lze otevřít i uprostřed kroku a změny pravidel se uplatní na zbytek aktuálního kroku. Za běhu funguje také /add-dir <path>. V celoobrazovkovém TUI se uprostřed kroku otevřou i dialogy /add-dir, /autocompact, /theme, /help, /config a /advisor.

Interpretace: nejpraktičtější je možnost upravit oprávnění v okamžiku, kdy zjistíte, že Claude potřebuje přístup jinam nebo naopak míří příliš daleko. Nemusíte krok přerušovat a začínat znovu. Změna pravidel s okamžitým účinkem je užitečná i z bezpečnostního hlediska. (v2.1.234) Dokumentace

Vestavěný styl výstupu „Concise"

Nový vestavěný styl výstupu vede Clauda k tomu, aby začínal výsledky a vynechával úvody i komentování vlastního postupu, přičemž práci odvádí stejně důkladně. Vybírá se v /config v části Output style. Související oprava zajišťuje, že vlastní styly, styly projektu a styly z pluginů se uprostřed relace nevracejí k výchozímu hlasu.

Interpretace: styl osloví hlavně ty, kdo čtou desítky odpovědí denně a výsledek potřebují vidět hned. Oprava driftu je důležitá pro týmy, které si styl výstupu definují vlastní a spoléhají na jeho stálost. (v2.1.237) Dokumentace

Kontrola pravopisu v promptu

Nové volitelné nastavení spellcheck podtrhává chybně napsaná slova v promptu během psaní. Využívá nainstalovaný aspell, hunspell nebo ispell.

Interpretace: jde o drobné pohodlí, které ale může pomoci tam, kde překlep v promptu změní zadání. Zda půjde dobře používat s češtinou, závisí na slovnících nainstalovaných v systému. Zdroj to neuvádí, před tiskem doporučuji ověřit. (v2.1.235) Dokumentace

Drobnosti

  • Nová proměnná prostředí ANTHROPIC_DEFAULT_MODEL určuje model, na kterém začínají nové relace; volba přes /model ji stále přebije a přetrvá i restart, na rozdíl od ANTHROPIC_MODEL.
  • Nastavení keybindingFlavor: "readline" nechává Ctrl+W mazat zpět po předchozí mezeru jako v Bashi a sjednocuje s Bashem i Alt+F, Ctrl/Option+→ a Alt+D.
  • Odznak merge requestu z GitLabu se objeví v patičce a ve stavovém řádku u repozitářů s GitLab remote a přihlášeným glab CLI.
  • Vestavěný skill claude-api se načítá za zhruba 25 tisíc tokenů místo více než 200 tisíc a /claude-api upgrade převádí projekty v Pythonu z anthropic 0.x na 1.x.
  • Vlastní prompty v přepisu se nově vykreslují jako markdown (zvýrazněné bloky kódu, inline kód, seznamy) stejně jako odpovědi.
  • Rozšíření pro VS Code přidává podporu čteček obrazovky pro přepis, s živým oznamováním a navigací po nadpisech jednotlivých kroků.
  • Opravena prompt cache u relací s LLM gateway nebo vlastní base URL a při opětovném připojení language serveru uprostřed relace, které dříve zneplatnilo celou cache.
  • Celoobrazovkový renderer se nově nabízí jednou i na Bedrocku, Vertexu, Foundry a dalších dříve vyloučených konfiguracích, kde nové instalace startují celoobrazovkově.
  • Pluginové marketplaces podporují headersHelper, příkaz generující HTTP hlavičky (např. krátkodobé tokeny) pro stahování katalogu a archivů, spouštěný po schválení při instalaci či aktualizaci.
  • claude self-hosted-runner přidává --defer-shutdown-max-min pro obsluhu relací po SIGTERM a --proxy-authorization-command/--proxy-authorization-file pro egress proxy.
  • Odhady nákladů (/cost, stavový řádek, --max-budget-usd) nově zahrnují příplatek 1,1× za inferenci pouze v USA u workspaců s datovou rezidencí.
  • Ctrl+L a Cmd+K v celoobrazovkovém režimu už jen překreslují; zkratka /clear dvojitým stiskem byla odstraněna.
  • Remote Control lépe odolává výpadkům: toleruje krátká odmítnutí HTTP 403 až 3 minuty, opakuje pokusy po potížích s obnovou přihlášení a při ukončení CLI označí relaci jako offline během několika sekund.

Závěr

Období není o jedné velké novince, ale o tom, že Claude Code snáší delší a samostatnější práci. Automatické pokračování po limitu, kontroly /goal a upozornění mezi relacemi míří stejným směrem: méně ručního dohlížení. Pro uživatele provozující více relací a dlouhé úlohy je proto nejzajímavější trojice notify_when_idle, /goal a pokračování po limitu. Správci a bezpečnostně orientované týmy ocení úpravu /permissions za běhu a podporu headersHelper či proxy autorizace. Ostatní si nejspíš nejdřív všimnou stručného stylu výstupu, kontroly pravopisu a úspory při načítání claude-api. Opravy prompt cache pak potichu snižují náklady tam, kde se používá gateway nebo vlastní base URL.
